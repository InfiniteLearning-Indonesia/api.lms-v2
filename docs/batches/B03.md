## Automation dan batas lanjut

Backend sanitization tests tidak menandai renderer frontend aman. M09 kemudian menambahkan grading terhadap immutable submission revision.

Authority gate: Backend implementation dan synthetic object/DB fixtures; real R2 privacy changes atau historical copy memerlukan scope/backup approval tersendiri.

STOP jika: Public proof leak, unsafe outbound, overwritten submitted work, cross-Class FK failure atau deadline/idempotency inconsistency.

QA yang gagal memicu perbaikan+rerun dalam scope, bukan skip test atau otomatis lanjut dependency. Sesi/limit terputus → simpan checkpoint → verifikasi evidence/worktree saat resume. Tidak perlu memberi instruksi terpisah per M yang sudah masuk scope gelombang, tetapi izin operasi baru tetap diminta ketika diperlukan.
