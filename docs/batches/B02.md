## Automation dan batas lanjut

M04 fixture pass bukan final integration pass. B03 hanya menggunakan policy/Class contract yang stabil dan terverifikasi untuk real integration.

Authority gate: Go implementation/local harness/approved synthetic DB scope. Schema migrations tetap mengikuti backup gate. Identity bridge/product capability defaults perlu reviewer.

STOP jika: Unsafe config, auth/privilege escalation, partial enrollment/audit transaction atau missing real Class integration.

QA yang gagal memicu perbaikan+rerun dalam scope, bukan skip test atau otomatis lanjut dependency. Sesi/limit terputus → simpan checkpoint → verifikasi evidence/worktree saat resume. Tidak perlu memberi instruksi terpisah per M yang sudah masuk scope gelombang, tetapi izin operasi baru tetap diminta ketika diperlukan.
