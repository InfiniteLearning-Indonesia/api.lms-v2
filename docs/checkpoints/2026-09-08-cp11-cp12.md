## Batas yang masih harus ditutup

1. Legacy tetap pemilik password/profile/provisioning/invite/reset dan identitas global. Adapter ke legacy yang benar-benar hardened belum diimplementasikan atau diuji. Penolakan endpoint owner-only bukan bukti fitur invite/reset sudah tersedia. Temuan legacy pada ADR tetap terbuka.
2. Assertion/freshness maksimal 60 detik. Session memiliki window 15 menit dengan absolute limit 1 jam, tetapi kehilangan assertion segar menyebabkan akses ditolak setelah freshness habis. Refresh authority/reauth UX, key rotation/custody/recovery dan transport legacy nyata wajib diselesaikan sebelum rollout.
3. Last-admin melindungi demotion **site-role lokal**. Signed disable dari owner tetap dihormati, termasuk bila menyebabkan nol admin lokal; invariant admin global wajib di owner. Demikian juga disable akun Teacher dari owner dapat menghilangkan staff aktif pada Class; diperlukan operational remediation, bukan mengabaikan pencabutan identitas demi availability.
4. Fence lokal berlaku bila semua penulis mematuhi protokol lock. Tidak menjanjikan revoke remote instan. Global advisory fence dan serialisasi Class membatasi throughput; perlu load/deadlock/timeout/cancellation/commit-uncertainty testing sebelum runtime produksi.
5. Limiter challenge 120/menit masih per-process dan coarse; batas lintas-instance, abuse protection exchange/projection dan operational logging belum full. HTTP API tests memeriksa atribut cookie, bukan perilaku browser atau produksi TLS/proxy.
6. General migration/operator runner, deployed API readiness, outbox worker, provider integration dan CI PostgreSQL adalah CP13/gate berikutnya. Grouping, mentor, retake, nested content ancestry dan content-ready publish tetap full M05/M07 scope berikutnya.
