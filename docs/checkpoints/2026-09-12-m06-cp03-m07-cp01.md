## Capaian

### M06-CP03 — bounded outbound fetch

- Fetcher Go memakai exact-host allowlist, HTTPS port 443, TLS minimum 1.2, proxy/compression off, fixed outbound headers, timeout/byte/redirect/concurrency budget.
- DNS divalidasi sebelum request dan kembali saat dial. IP loopback/private/link-local/multicast/unspecified serta reserved/test/bogon ditolak; redirect divalidasi ulang dan URL dengan userinfo/fragment/IP literal gagal tertutup.
- Remote file import melakukan authorization Class/owner sebelum DNS/network, memakai idempotency yang mengikat URL, lalu melewati quarantine/scan/promotion flow yang sama dengan upload.
- Response content type/encoding dan declared file media type harus cocok; oversized, timeout, transport error dan provider tanpa konfigurasi tidak menjadi file AVAILABLE.

### M07-CP01 — content/activity foundation

- Schema additive `v3.content_sections`, `v3.content_activities`, dan `v3.content_commands`; semua relasi Class/section/user memakai FK dan index, urutan unik dibatasi DB, tanpa cascade/delete path.
- API Go untuk ordered Class content: create/update section, create/update activity dan read snapshot. Activity type CP01 dibatasi `RESOURCE`, `ASSIGNMENT`, `QUIZ`.
- Teacher aktif dalam Class dan site admin dapat author; Student aktif hanya dapat membaca content Class published; outsider, suspended membership, foreign ancestry dan stale version ditolak.
- Command write idempotent, optimistic versioned, dan menulis domain change + audit + outbox dalam satu transaksi pendek. Respons pertama/replay memakai canonical JSONB yang byte-stable.
