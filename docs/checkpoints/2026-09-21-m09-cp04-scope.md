## Evidence legacy dan keputusan konservatif

- Legacy `classes.service.ts` memproyeksikan missing, falsy, NaN-like, dan nilai di bawah 65 menjadi displayed 65; ini bukan raw grade authoritative.
- Legacy AI evaluator memakai fallback 75 pada parse/provider failure dan beberapa flows menulis 75 ke submission. Fallback tersebut tidak boleh otomatis menjadi canonical grade.
- `competency_scores` dan `rubrik_assessment_scores` hanya unik terhadap learner + competency/rubric; Class/run/episode tidak menjadi bagian identitas. Satu row tidak boleh disebarkan ke semua Class.
- CP04 menyimpan reconciliation ledger immutable, bukan memigrasikan atau mengubah canonical grade. Original source snapshot hash, source row identity, exact raw representation, normalized raw score bila tersedia, observed/displayed score, origin, scope, candidate mapping, canonical released comparison, outcome, actor dan policy reference dipertahankan.
- `MISSING_ROW`, `EXPLICIT_NULL`, dan `VALUE` berbeda. Literal zero adalah `VALUE` dan tidak boleh berubah menjadi missing atau 65.
- `LEGACY_MINIMUM_65`, `AI_FALLBACK_75`, dan `PROGRAM_GLOBAL` selalu ditahan untuk review. Mereka tidak dapat disetujui sebagai difference melalui API CP04.
- Class-scoped row hanya dibandingkan dengan exact Class + grade item + aggregate dan released revision terakhir. Grade draft/unreleased tidak menjadi canonical comparison.
- Exact mismatch boleh direkam sebagai `APPROVED_DIFFERENCE` hanya oleh site admin, dengan policy reference dan reason eksplisit. Ini membuktikan kontrak teknis sintetis, bukan persetujuan academic owner untuk data nyata.
- Ledger append-only, idempotent per actor/key, atomic bersama audit/outbox, dan tidak mempunyai privilege UPDATE/DELETE untuk runtime.
