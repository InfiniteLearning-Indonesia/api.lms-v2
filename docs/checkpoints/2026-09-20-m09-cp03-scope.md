# Scope freeze — M09-CP03 (20 September 2026)

Status: **FROZEN BEFORE IMPLEMENTATION**. Backend Go dan PostgreSQL sintetis lokal saja. Tidak ada akses staging/production, copy data nyata, deployment, frontend, commit, atau push. Migrasi additive hanya setelah backup SQL + custom dump dan actual isolated restore proof.

## Keputusan bisnis sementara untuk slice lokal

- Import ditujukan hanya untuk nilai assignment yang **sudah handed-in** dalam satu Class dan satu grade item; request tidak pernah menetapkan learner ID. Tidak ada import program-global, cohort-wide, AI score, atau legacy 65/75 mapping pada CP ini.
- Active Class Teacher atau site admin dapat membuat preview, mengonfirmasi import, dan merilis grade. Learner/outsider tidak. Actor tidak boleh mengimpor atau merilis nilai miliknya sendiri.
- Preview adalah draft immutable yang **tidak mengubah grade**. Ia mengikat actor, Class, grade item, exact input hash, published definition version/revision, expected current grade version, serta expiry pendek. Konfirmasi mengulang validasi konteks, policy, submission receipt, dan current version dalam satu transaksi; preview stale/expired ditolak.
- Import merevisi grade yang sudah ada hanya bila ada reason non-kosong. Initial import memakai reason `IMPORT_INITIAL`. Maksimal 50 row per preview; aggregate duplikat ditolak. Semua row harus valid; kegagalan satu row membatalkan seluruh confirm.
- Release berlaku per current grade revision/aggregate, explicit dan immutable. Regrade sesudah release **tidak otomatis terlihat**; learner tetap melihat revision terakhir yang pernah dirilis sampai release revision baru. Release berbeda untuk grade revision yang sama ditolak; retry key yang sama mengembalikan receipt lama.
- Learner hanya dapat membaca nilai released miliknya dalam Class dengan enrollment aktif. Draft/current yang belum dirilis tetap privat. Teacher/admin tetap dapat membaca current grade.
- Kebijakan ini dibekukan untuk synthetic slice dan perlu review academic owner sebelum shared runtime/pilot. Bukan approval untuk mengubah nilai historis nyata.
