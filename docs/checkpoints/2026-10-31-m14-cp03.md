Export is private synchronous CSV with safe filename, formula-neutralized title cells, no-store, scoped access audit and isolated outbox topic committed before bytes are sent. No public storage URL or real outbound delivery.

## Deliberate scope limits

- Single synthetic handler holds a random ephemeral cursor key; restart invalidates cursors. Multi-instance/shared-key lifecycle needs separate deployment policy.
- Conservative 200-item report and 256 KiB limits return explicit 413; no asynchronous bulk export or performance benchmark claim. Wider reporting/export needs remain canonical gates.
- Export retries intentionally create separate access audit entries. They do not mutate grades; this is not an exactly-once job contract.
- No shared database access, schema migration, database deletion, real provider, frontend, commit, push or deployment.
