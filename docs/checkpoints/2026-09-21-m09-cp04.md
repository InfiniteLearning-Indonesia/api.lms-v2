- Ledger `legacy_grade_reconciliation_runs` dan `legacy_grade_observations` bersifat append-only, idempotent per actor/key, dan menyimpan source snapshot hash, source row identity, exact raw representation, normalized raw score, observed score, origin, scope, candidate mapping, canonical released comparison, outcome, reason, policy reference, serta actor.

- Program-global competency/rubric rows tanpa Class identity selalu `AMBIGUOUS_HOLD` dan tidak disebarkan ke Class mana pun.
- Comparison Class-scoped memakai exact Class + grade item + submission aggregate dan released revision terakhir. Draft/unreleased grade menghasilkan `NO_CANONICAL_HOLD`.
- Exact mismatch hanya dapat dicatat sebagai `APPROVED_DIFFERENCE` oleh site admin dengan policy reference dan alasan eksplisit. Ledger tidak pernah menulis atau memperbarui canonical grade.
- Mutation memakai transaction-level advisory locks dengan urutan deterministik, audit/outbox atomik, FK komposit, dan indeks seluruh foreign-key/query path. Runtime hanya memiliki SELECT/INSERT; UPDATE/DELETE tidak diberikan.
