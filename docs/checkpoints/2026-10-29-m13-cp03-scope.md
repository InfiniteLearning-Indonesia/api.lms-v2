# M13-CP03 — frozen local-synthetic AI suggestion scope

Frozen 29 October 2026 before implementation. Exactly one CP. Backend Go only; the provider is an in-process deterministic rehearsal stub. No live model, network egress, student data export, credential, shared database, staging/production mutation, deployment, commit or push.

## Bounded policy

1. Only assigned Class Teacher or Admin can request/read suggestions for an exact submitted revision and current published rubric. The student, peer Class and unassigned actor cannot create/read them. Provider receives bounded submission text and rubric metadata, never credentials or private attachments. The suggestion is append-only, Class/aggregate/revision-bound and records model, prompt, rubric and submission provenance hashes.
2. Provider failures create an explicit failed suggestion with a bounded error code and **no score**. No fallback 75 or other implicit pass/grade; raw student prompt cannot change authorization, SQL or grade state. The rehearsal stub is deliberately not a quality claim about real AI.
3. A suggestion never writes the gradebook or completion state. Human review uses the existing M09 grade endpoint, supplying an optional exact suggestion ID. The server and DB reject a foreign/failed/mismatched suggestion; the reviewer still supplies the final value and gradebook's normal authority/version checks apply. No automatic approval or release.
4. New schema is additive and append-only. Before applying it in QA, create SQL/custom backups and prove an isolated restore. Use existing synthetic `qa_cp05` only, no DELETE/TRUNCATE/DROP. Runtime receives minimal SELECT/INSERT grants, no UPDATE/DELETE on suggestion history.
