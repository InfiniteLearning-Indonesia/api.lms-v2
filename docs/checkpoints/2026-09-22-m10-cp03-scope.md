# Scope freeze — M10-CP03 transcript and credential lifecycle

Frozen before implementation on 22 September 2026. Environment: new loopback synthetic PostgreSQL only. No staging/production access, data copy, DELETE/TRUNCATE/DROP, commit or push.

## Contract

- Class teacher/site admin explicitly releases an immutable learner/episode transcript from **released** grades only. Each item preserves grade release/revision, raw milli-value, scale minimum/maximum, definition version, weight and a fixed synthetic policy reference. Snapshot remains unchanged after grade correction/re-release.
- Credential issue is explicit (never caused by grade release/import), Class-scoped, requires an active completed progress projection and a current transcript source fingerprint. Identifier is opaque; issuance is idempotent. Revoke and supersede append history with actor, reason and version, never rewriting issued credentials.
- Public verification returns minimal status only for PUBLIC_MINIMAL credentials; PRIVATE credentials are indistinguishable from unknown identifiers. HTTPS-only, bounded public rate, no PII/grade/learner in public response. Authenticated mutations retain session/CSRF, contextual teacher authority, audit+outbox atomicity.
- Backup SQL/custom and actual isolated restore before additive `m10-cp03-1`. No academic policy claim beyond synthetic fixture.

## Excluded

Real academic graduation policy, certificate PDF/design, legacy observed output import and issuance suppression mapping (CP04), shared runtime deployment, production/staging migration.
