# M07-CP04 — frozen local-synthetic content closure scope

Frozen 30 September 2026 before implementation. One CP only. Depends on the M07-CP01–03 producer, M08 exact-revision submission consumer and M05 Class integration. This is **not** live import, production deployment, or canonical M07 acceptance.

## In scope

1. Permit an authenticated historical submission owner to resolve **only the exact assignment revision** referenced by their own aggregate after withdrawal or enrollment end. Return safe canonical content/rule, never `content_revision_sources.raw_body`. A peer without that work, foreign Class actor, or unreferenced draft remains denied. Current assigned Teacher/Admin access is preserved.
2. Transactional, idempotent `POST /v3/classes/{target}/content/clone` copying **only sections and activity shells** from a source Class into an empty DRAFT target. Actor must be assigned Teacher on both Classes or Admin. Source must be PUBLISHED or ARCHIVED, target distinct and DRAFT. No revisions, raw bodies, assignment rules, files, learners, enrollments, submissions, grades, completion or credentials are copied. Existing `content_commands` response plus audit/outbox retain source/target ID mapping. Bounded at 50 sections/200 activities; concurrent clone and key collision fail closed.
3. Pure, bounded preview adapter for legacy `importantLinks` v1 (live `id/title/url/iconType`) and v2 (staging optional `scope/programs`). It never writes DB or fetches URLs; v1 has review-required scope, v2 preserves explicit scope/program strings without assigning Class access. Unknown JSON shape, unsafe URL or unsupported version is rejected. Real-source version/profile and academic authorization remain external gates.
