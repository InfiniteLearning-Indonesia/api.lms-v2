# Scope freeze — M10-CP01 completion-policy foundation

**Frozen:** 21 September 2026, sebelum implementasi. **Environment:** PostgreSQL sintetis loopback baru saja; staging/production dilarang. **Destructive SQL:** dilarang (`DELETE`, `TRUNCATE`, `DROP`).

## Outcome

Membangun fondasi completion yang tidak menyamakan nilai dengan completion: versi rule immutable, evidence eksplisit dan outcome evaluasi yang terikat Class, learner episode, activity revision, serta rule snapshot.

## In scope

- Rule `EVIDENCE_PRESENT` versi berurutan untuk activity revision yang sudah published.
- Evidence `ACTIVITY_ACKNOWLEDGED` yang hanya dapat dicatat oleh learner aktif untuk dirinya sendiri.
- Outcome append-only `COMPLETED` atau `INCOMPLETE`; nilai tinggi tanpa evidence tidak menghasilkan completion.
- Contextual teacher/admin rule authority; active learner evaluation authority; foreign Class/activity/revision/episode fail closed.
- Idempotency, transaction-level advisory locking, audit+outbox atomicity, immutable history, least-privilege runtime grants.
- Backup SQL/custom dan actual isolated restore sebelum installment `m10-cp01-1`.

## Explicitly out of scope

- Progress/current projection, override, reopen dan event replay repair (M10-CP02).
- Transcript/certificate lifecycle (M10-CP03).
- Legacy completion/output import dan closure M10 (M10-CP04).
- Staging/production migration, deployment, data copy, commit atau push.

## Frozen mandatory cases

| Layer | Case ID | Assertion |
|---|---|---|
| Go/DB | `TestSyntheticCompletionRuleSnapshot` | Teacher creates sequential immutable rule snapshots; replay is identical. |
| Go/DB | `TestSyntheticCompletionOutcomeSeparation` | Explicit evidence completes without grade; a high released grade without required evidence remains incomplete. |
| Go/DB | `TestSyntheticCompletionBoundary` | Unauthorized/foreign/stale writes fail closed; injected outbox failure rolls back evidence, outcome, command and audit. |
| Playwright | `M10-CP01-rule-snapshot` | HTTPS/API rule versioning, strict input and idempotent replay. |
| Playwright | `M10-CP01-grade-separation` | Complete-without-grade and high-grade-without-evidence behavior is observable through API. |
| Playwright | `M10-CP01-security-boundary` | Learner/outsider cannot author policy; outsider/foreign context cannot create evidence; response/logs do not leak credentials. |

## Exit criteria

1. Exactly 3/3 frozen Go/DB and 3/3 frozen Playwright cases pass.
2. Full dependency regression through M09 passes on the same new synthetic cluster.
3. Backup and actual restore proof precede schema installment; migration replay checksum passes.
4. Reconciliation finds no orphan rule/evidence/outcome, no completed outcome without matching evidence, and no runtime `UPDATE`/`DELETE` privilege on completion history.
5. Evidence records source hash, test coverage, backup hashes and safety profile. Local success is not production approval.
