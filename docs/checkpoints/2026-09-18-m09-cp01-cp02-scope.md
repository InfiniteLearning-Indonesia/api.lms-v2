## Safety boundary

- Backend Go only; no frontend work.
- New local, loopback-only synthetic PostgreSQL cluster only.
- Staging and production databases are out of scope and must not be contacted.
- Every installment requires a fresh custom-format dump, rendered SQL, and a successful isolated restore/reconciliation before DDL runs.
- Migrations are additive. Runtime roles receive no `DELETE`, `TRUNCATE`, schema-owner, or migration privileges.
- No commit or push is authorized by this checkpoint run.

## M09-CP01 — grade definitions

Deliver one Class-scoped grade item per assignment activity, immutable integer score scales, immutable definition versions, hierarchical rubric criteria, and append-only publication events.

Rules:

- Scores use integer milli-units; floating point is prohibited.
- Weight uses basis points (`1..10000`). Published rubric leaf weights must total exactly `10000`.
- Missing/ungraded is represented by absence, never by an implicit zero or fallback score.
- Rubric parentage must stay inside one definition version; dangling parents and cycles are rejected.
- A published definition is immutable. Changes require a new version and a new publication event.
- Publication uses an expected publication revision and conflicts on stale concurrent writes.
- Only an active teacher in the Class or a site admin may author/publish/read draft definitions.
- Definition write, audit, outbox, and idempotency receipt are one transaction.

Out of scope: grade import, learner release, gradebook aggregation, legacy reconciliation, UI.

## M09-CP02 — scoped grading and regrade concurrency

Deliver append-only grade revisions plus a mutable current projection for a receipt-backed submission revision.

Rules:

- The server derives learner, attempt, Class, assignment, and exact handed-in revision from M08 records.
- A grade must use the latest published definition for the matching assignment activity.
- A grader must be an active teacher in that Class or a site admin and may not grade their own submission.
- Initial grade expects version `0`; regrade requires the current version and a non-empty reason.
- Value must remain inside the published scale bounds.
- Concurrent/stale graders produce one winner and one `409 CONFLICT`; history is never overwritten.
- Grade history, current projection, audit, outbox, and idempotency receipt are one short transaction with deterministic advisory locking.
- Learners cannot read unreleased grades. Release is reserved for M09-CP03.

Out of scope: learner visibility, bulk import, grade aggregation, completion derivation, legacy reconciliation, UI.
