# Scope freeze — M13-CP01 dan M13-CP02

Tanggal freeze: 16 September 2026. Scope: backend Go dan PostgreSQL sintetis loopback saja.

## Batas checkpoint

- **M13-CP01 — durable delivery:** receipt provider yang immutable dan lease-fenced; worker at-least-once mencatat receipt sebelum ACK; retry/dead-letter/attempt/receipt dapat dilihat site admin tanpa payload atau referensi provider mentah.
- **M13-CP02 — notification safety:** preference email per pengguna; provider binding hanya menyimpan `secretref://...`; delivery operasional hanya `QUEUED` bila preference dan provider aktif; historical import selalu `SUPPRESSED`; sink QA hanya rehearsal dan tidak melakukan network send.
- Tidak termasuk AI suggestion (M13-CP03), provider/SMTP nyata, secret material, frontend, deployment, atau perubahan database bersama.

## Kontrak hasil

- PASS lokal hanya bila seluruh case frozen PASS, source hash sama dengan tested hash, migrasi punya bukti backup/restore, dan regresi yang relevan lulus.
- `EventID` adalah provider idempotency key. Sistem menjamin at-least-once, bukan exactly-once; duplicate provider response harus eksplisit.
- Receipt menyimpan provider key/outcome dan SHA-256 reference saja. Provider binding menyimpan reference, bukan secret value.
- External gates tetap terbuka: provider nyata, secret manager nyata, shared runtime wiring, remote CI, dan kebijakan recipient/template produksi.
