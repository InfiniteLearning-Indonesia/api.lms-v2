## Implementasi

`internal/labdb/m12.go` memasang schema additive `logbook_period_sets`, `logbook_periods`, `logbook_period_publications`, dan command receipt dengan FK lintas-Class, indeks FK, unique publication revision, trigger immutability/overlap/urutan ordinal. Installer hanya menerima target `qa_fixture` marker-bound loopback dan backup+actual isolated restore yang baru. Role QA runtime mendapat `SELECT/INSERT` pada tabel logbook; `UPDATE` pada parent set hanya untuk row lock trigger, dan update isi tetap ditolak oleh trigger. Tidak ada grant `DELETE/TRUNCATE`.

`internal/logbook/periods.go` membuat snapshot DRAFT berisi 1–24 periode eksplisit, validasi IANA timezone dan `starts_at < ends_at <= due_at`, menolak overlap/urutan terbalik, batas 1.000 snapshot per Class, lalu memublikasikan lewat event append-only dengan expected active set. Admin/Teacher aktif pada Class dapat menulis; Student aktif hanya membaca set terpublikasi pada Class terpublikasi. Snapshot lama tetap dapat dibaca Teacher/Admin melalui ID tanpa menimpa data. Idempotency, Class lock, audit dan outbox berada dalam transaksi yang sama. HTTP QA `/v3/classes/{id}/period-sets` dan `/{setID}/publish` di `internal/logbook/http.go` memakai gateway auth/CSRF, parsing JSON ketat, no-store dan batas body. Endpoint baru **baru di-wiring pada `cmd/identity-lab` sintetis**, belum di `cmd/api` runtime bersama; karena itu canonical M12-D01 belum dianggap selesai.

CP ini tidak membuat logbook entry, review, grade, attendance, jadwal empat bulan otomatis atau mapping Batch historis. Batas jumlah dan `due_at >= ends_at` adalah kontrak uji lokal yang masih perlu persetujuan product owner sebelum diterapkan ke pengguna nyata.
