# M05-CP05 — frozen local integration scope

Frozen 29 September 2026 before implementation. This is a **synthetic-only** Class/content/work/grade integration slice, not full M05 canonical acceptance or permission to migrate/deploy.

## Dependencies and boundary

- Reuse M05-CP01–04, M07 publish, M08 submission and M09 grade/release contracts. No new production schema or frontend work.
- Add only an opt-in lab QA route profile, exact Go/DB and Playwright cases, runner reconciliation and documentation. Never access staging/live databases.
- Keep existing academic history immutable across end/retake. A new episode must not inherit an old aggregate/grade. Retained history is visible to an assigned Teacher; ended Student must not create new work or read a grade via the active-learner route.
- The optional cohort/program labels do not confer authority; only active Class-scoped Teacher can publish/edit/grade.
