# Scope freeze — M10-CP02 progress, override and reopen

Frozen before implementation on 22 September 2026. Only a fresh loopback synthetic PostgreSQL cluster may be used. No staging/production access, DELETE/TRUNCATE/DROP, commit or push.

## Contract

- Derive Class/learner activity progress from the latest published completion rule, its append-only learner outcome, and append-only corrections. The read projection is rebuilt from canonical history on each request; GET never repairs or writes state.
- A Class teacher or site admin may explicitly override to complete/incomplete, or reopen a completed activity. Require a bounded nonempty reason, optimistic expected version, current Class/episode/rule scope, idempotency, audit and outbox in one transaction.
- Learner evaluation cannot silently undo an override. Reopen permits subsequent learner evaluation. Grade/release never implies progress/completion.
- Preserve previous outcomes/corrections; no mutation of historical records. Backup SQL/custom and actual isolated restore before the additive `m10-cp02-1` installment.

## Excluded

Transcript, certificate, legacy output import, shared runtime, real migration and academic policy selection (CP03/CP04 or later gates).

Exactly 3/3 Go/DB and 3/3 Playwright frozen cases, full M09/M10-CP01 dependency regression, migration replay, backup/restore proof, correction/context/audit/outbox reconciliation, source hash and coverage. Local pass is not canonical M10 closure.
