## Contract

- Operator-only, explicitly invoked intake records source instance, snapshot hash, source table/PK/version, raw payload/hash and observed legacy output state. Ambiguous/unverified flag remains `OBSERVED_UNVERIFIED`; no automatic completion, transcript release, credential issuance, notification or outward event is inferred.
- Rows are append-only and keyed by source identity plus version. Same operator idempotency key and normalized request returns the same run; key/body mismatch or conflicting source identity is rejected atomically. Unknown/invalid legacy values are retained as raw evidence with `UNKNOWN_HOLD`, not silently mapped.
- A candidate Class/learner pair is accepted only when both IDs exist and the learner belongs to that Class; candidate is a reference for review, not authorization to write canonical academic state. Program-global/unmapped evidence stays unassigned.
- Correcting a grade/releasing a later transcript cannot mutate an older transcript or credential. Historical observations do not alter public credential verification.
- A SQL/custom backup and actual isolated restore must precede additive `m10-cp04-1`; migration replay, DB reconciliation, role privilege checks, Go/DB and Playwright API tests plus full dependency regression required. No fake production parity claim.

## Excluded

Production adapter, real academic policy approval, source truth adjudication, actual live/staging migration, shared `cmd/api`, frontend and remote CI. Full canonical M10 remains gated even if this fixture slice passes.
