# Scope freeze — M12-CP01 (Class logbook periods)

Frozen before implementation. One backend-Go CP only; no M11-CP02, entry/review lifecycle, frontend, production/staging access, commit or push.

## Local synthetic contract

- One Class owns immutable period-set snapshots and arbitrary 1–24 named periods per snapshot. Each period has explicit `starts_at`, `ends_at`, `due_at` UTC instants and an IANA timezone; the first period must start before its end, deadline cannot precede its end, and periods within a snapshot cannot overlap. No fixed 4-month schedule or inferred dates.
- Admin or active Teacher of that Class can create DRAFT set and publish it. Active Student can read only the latest PUBLISHED set for a published Class; Teacher/Admin can read draft as well. Foreign Class/ended/suspended actor denied. Class archival/closure stops writes.
- Publishing is explicit and append-only. One active published set is derived from the latest publication event, so correction creates a new snapshot without rewriting history. Cross-Class FK, idempotency, Class lock, audit+outbox in one short transaction.
- Max 24 periods and 1000 visible historical snapshots are safety bounds, not a final product policy. Actual calendar/timezone and rollout policy remain owner gates. No logbook entry/attendance/grade data is created.
