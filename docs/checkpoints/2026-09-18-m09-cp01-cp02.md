## M09-CP01 — grade definition, scale, dan rubric version

Schema additive di `internal/labdb/m09.go` memisahkan grade item per assignment activity, integer score scale, definition version, hierarchical rubric criterion, publication event append-only, dan idempotency receipt. Score memakai milli-unit integer dan weight memakai basis point; missing/ungraded tetap berarti tidak ada grade row, bukan angka nol atau fallback. FK komposit dan indeks menjaga Class/activity/scale/version ancestry. Publication menolak rubric kosong, leaf weight selain 10.000, dangling parent, cycle, stale revision, dan reuse version.

Scale, item, version, rubric, publication, dan command receipt immutable terhadap update. Perubahan aturan dilakukan dengan version baru dan publication event baru. Active Teacher dalam Class atau site admin boleh author/publish/read draft; outsider ditolak. Definition mutation, audit, outbox, dan idempotency receipt berada dalam satu transaksi. Publication memakai advisory transaction lock agar konkurensi serial tanpa memberi runtime privilege UPDATE pada definition table.

## M09-CP02 — scoped grade dan concurrent regrade

`internal/gradebook` menurunkan learner, attempt, Class, assignment, dan exact handed-in submission revision dari M08; request tidak boleh menentukan learner. Initial grade memakai expected version 0. Regrade wajib menyertakan reason dan current version. Grade di luar bound, foreign ancestry, actor di luar Class, self-grade, stale concurrent write, dan learner read sebelum release ditolak.

`grade_revisions` adalah histori append-only. `grade_current` hanya projection yang menunjuk revision history exact. Write memakai deterministic advisory lock dan compare-and-swap: dua grader dengan expected version sama menghasilkan satu winner dan satu conflict. History, current projection, audit, outbox, dan idempotency receipt atomic dalam transaksi singkat. Failure injection membuktikan tidak ada partial grade/current/audit/command yang tertinggal. Release ke learner tetap di luar scope dan menunggu M09-CP03.
