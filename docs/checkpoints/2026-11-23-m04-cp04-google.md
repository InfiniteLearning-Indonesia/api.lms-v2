## Kontrak API

`POST /v3/auth/google/start` menerima JSON dan origin HTTPS LMS yang ditetapkan. Ketiga mode memakai cookie binding HTTPS, HttpOnly, SameSite Strict dengan masa berlaku 5 menit. Respons memuat `authorization_url` untuk navigasi ke Google.

| `mode` | Body tambahan | Syarat |
|---|---|---|
| `login` | — | Google subject sudah tertaut pada akun LMS aktif. Email baru pada akun Google tidak memindahkan identitas LMS. |
| `invite` | `invite_token` | Akun sudah dibuat Site Admin. Token undangan masih aktif. Email Google terverifikasi dan cocok dengan target undangan. Aktivasi dan link terjadi di transaksi yang sama. |
| `link` | `email`, `password` | Sesi dan CSRF sah di awal, password dikonfirmasi ulang, serta email Google terverifikasi dan cocok dengan target. Penyelesaian mengikat sesi asal yang sama dan menggantinya dengan sesi baru. |

Daftarkan URL persis `<origin>/auth/google/callback` di Google Cloud. Halaman landing dari origin yang sama memproses penolakan Google secara lokal. Untuk response yang sukses, ambil `state` dan `code`, bersihkan query dari address bar, lalu kirim JSON kedua field ke `POST /v3/auth/google/complete`. Sajikan halaman tersebut dengan `Cache-Control: no-store` dan `Referrer-Policy: no-referrer`, serta catat path callback tanpa query di access log server dan proxy. API mengembalikan cookie sesi LMS dan `csrf_token`. Flow diklaim sekali sebelum permintaan token ke Google. Jika pertukaran gagal, mulai flow baru. Satu tab dapat menggantikan cookie binding tab lain sehingga pengguna mungkin perlu memulai ulang flow lama.

Google memakai endpoint tetap, validasi RS256, penyegaran JWKS dengan batas waktu, serta pemeriksaan claims. Go menyimpan hash state/binding dan referensi bukti. Verifier PKCE dan nonce diturunkan dari key server 32 byte yang dibagi antarreplika. Simpan key flow terpisah dari secret client dan key delivery password. Database menyimpan issuer/subject dengan constraint unik dan tetap memakai ID akun yang sama. Untuk akun Google-only, jalur reset terverifikasi CP03 dapat menambahkan password untuk ID yang sama. [Google OpenID Connect](https://developers.google.com/identity/openid-connect/openid-connect) · [Metadata konfigurasi Google](https://accounts.google.com/.well-known/openid-configuration)
