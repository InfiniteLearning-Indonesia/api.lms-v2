# M14-CP01 — frozen scoped released-grade projection

Frozen before implementation. One read-only endpoint: `GET /v3/classes/{class_id}/reports/grades/{learner_user_id}`. Only active learner self, assigned active Class Teacher, or Admin can read; the target learner must have active, unsuspended Class enrollment. Output contains latest **released** grade per Class grade item, numeric value, grade version, release ID and release timestamp. Never expose grade draft, raw submission, email, provider metadata, or another Class. Exact source is `v3.grade_releases` joined to `v3.grade_revisions`; no asynchronous copy. `watermark` is the maximum release timestamp and release ID pair; empty state has null watermark. Mandatory Go/DB and Playwright cases: self, teacher, admin, foreign actor/learner/Class, unreleased grade, release then immediate read, subsequent release version. No schema change, export or pagination in this CP. Canonical M14-D01/D04 remain partial until wider projections and shared gates.
