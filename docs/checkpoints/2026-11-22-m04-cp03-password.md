**Verifikasi PostgreSQL dan HTTPS lokal sintetis lulus.** Run `20261122T151935Z-m04-password-bc74f4758b23` mencatat `PASS_M04_CP03_LOCAL_SYNTHETIC_ONLY`, `TestM04PasswordPostgresJourney`, 5 kasus Playwright, backup custom dan SQL yang cocok dengan hash receipt, pemulihan target kosong, dan shutdown normal. ## Kontrak lokal

| POST pada `/v3/auth/` | Akses dan hasil |
|---|---|
| `accounts/invite` | Site Admin dengan sesi, origin dan CSRF yang sah. Membuat akun invited atau menerbitkan ulang invitation yang belum diaktifkan. Akun aktif tetap memakai ID yang sudah ada. |
| `password/invite/accept` | Token tujuan invite yang masih berlaku. Menetapkan password dan mengaktifkan akun secara atomik. |
| `password/login` | Email yang dikanonisasi dan password. Login sukses menerbitkan cookie sesi dan nilai CSRF. Login gagal memakai respons generik. |
| `password/reset/request` | Respons 202 yang sama untuk alamat valid yang dikenal atau tidak dikenal. Hanya akun eligible menjadwalkan pengiriman. Permintaan berulang selama token masih aktif memakai permintaan yang sudah ada. |
| `password/reset/confirm` | Token tujuan reset sekali pakai. Ganti password dan cabut sesi lama dalam satu transaksi. |
| `accounts/suspend` | Site Admin dengan sesi dan CSRF. Suspend mencabut sesi dan token yang belum dipakai. Penangguhan Site Admin terakhir ditolak. |

Token di database berbentuk hash. Antrean pengiriman memuat AES-GCM ciphertext yang terikat pada akun, tujuan, dan ID pesan. Runner QA membaca ciphertext dari role fixture dan mengujinya di memori. Pengiriman email nyata, key custody dan pengaktifan jalur di runtime bersama masih perlu integrasi. Penugasan Invite Mentor/Mentee tetap berada di M05, setelah akun dibuktikan. Data identitas hasil impor M15 belum memiliki credential aktif.

### Keputusan skema password

Slice ini memakai `crypto/pbkdf2` dari Go, **PBKDF2-HMAC-SHA256 dengan 600.000 iterasi**, salt acak 16 byte, output 32 byte, serta identifier skema pada row credential. Argon2id tetap opsi yang disukai dalam rencana, tetapi dependensi dan rantai verifikasinya tidak tersedia pada lingkungan pengerjaan ini. Tidak ada dependensi Go baru. Parameter dan schema untuk runtime bersama direview sebelum penerapan ke akun nyata. [Go PBKDF2](https://pkg.go.dev/crypto/pbkdf2) · [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)
