## Verified flow and boundaries

- Draft Class cannot publish without assigned Teacher. A second assigned Teacher can author content and grade Class work; a foreign user cannot gain that authority from a cohort label or unassigned identity.
- Ended learner cannot create work or use the active-learner grade read. Assigned Teacher retains access to old submission and grade. Archive denies new work and Teacher's active grade read; the Teacher still reads old submission and Admin reads retained grade. This is a policy observation in the current code, **not** an approved long-term archive UX decision.
- Explicit retake creates a new episode and aggregate. The old aggregate and grade remain pinned to the old episode; no grade is inherited automatically.
- SQL reconciliation checks Class/enrollment/episode and grade/release ancestry, including retake origin. No destructive statement was used.
