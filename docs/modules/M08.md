## Tujuan dan scope

Submission learner tetap utuh saat resubmit, timeout/retry atau grading berlangsung bersamaan.

- Prioritas/kompleksitas: **P1 / Medium**; owner/reviewer belum ditetapkan.
- Dependency: M07/M06 dan enrollment/policy M05/M04.
- Coverage pekerjaan: Attempts/revisions, draft/hand-in receipt, idempotency, optimistic lock, cutoff dan file references.
- Di luar scope: Tidak submission UI, final AI grade, hard overwrite atau fake historical attempts.
- Area file: `internal/submissions/`, submission OpenAPI. Path Go/QA adalah usulan, belum file implementasi.
- Referensi: [ImplementationPlan §8/M08](../../../../ImplementationPlan.MD), serta §3–7 untuk domain/security dan §9–16 untuk data/test/cutover.

## Data safety, exit dan fallback

- Gate data: Backup dan origin mapping sebelum import; no DELETE duplicate submissions/test cleanup.
- Fallback: Ambiguous historical works read-only/quarantined; preserve acknowledged receipts.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: approval operasional tetap terpisah bila menyentuh environment nyata; backend QA tidak memberikan izin deployment.
