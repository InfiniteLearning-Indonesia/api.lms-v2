- Gate data: FK same-Class dan uniqueness pada schema baru; raw duplicates source retained; jangan mutate existing staging public.
- Fallback: Keep imported Class DRAFT; owner legacy tetap sampai cutover approved.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
