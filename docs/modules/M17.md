## Data safety, exit dan fallback

- Gate data: Fresh backup before final delta and explicit pilot approval; backend-first preparation does not authorize routing/deployment.
- Fallback: Before new writes: reviewed return LEGACY possible; after writes: HOLD_READ_ONLY+forward fix unless tested non-lossy reverse projection.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: M17-X01: later frontend login/cookie/CSRF, Class navigation, submission/retry/old-link flows and human maintenance/rollout approval mandatory; backend docs/tests cannot satisfy these.
