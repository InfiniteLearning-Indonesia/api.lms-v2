## Tujuan dan scope

File menjadi resource ber-owner dan ber-context, bukan public URL yang siapa pun dapat buka.

- Prioritas/kompleksitas: **P0/P1 / Medium**; owner/reviewer belum ditetapkan.
- Dependency: M03/M04 dan M05 context contract.
- Coverage pekerjaan: Private assets/references, validated upload/quarantine/scan, authorized download dan bounded egress.
- Di luar scope: Tidak file picker/frontend, tidak public proof fallback atau penghapusan object lama.
- Area file: `internal/files/`, platform outbound fetch; referensi legacy storage service. Path Go/QA adalah usulan, belum file implementasi.
- Referensi: [ImplementationPlan §8/M06](../../../../ImplementationPlan.MD), serta §3–7 untuk domain/security dan §9–16 untuk data/test/cutover.

## Data safety, exit dan fallback

- Gate data: Private copy/restriction dibackup dan diaudit; no overwrite key/delete. External references di-fetch hanya jika authorized.
- Fallback: Hold/quarantine unknown assets, bukan publish agar test terlihat hijau.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: approval operasional tetap terpisah bila menyentuh environment nyata; backend QA tidak memberikan izin deployment.
