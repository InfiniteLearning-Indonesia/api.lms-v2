## Data safety, exit dan fallback

- Gate data: Backup before each wave/migration; target staging becomes sensitive operational environment, never playground.
- Fallback: Stop subsequent waves; affected unit hold/forward fix; all histories/databases retained.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: M18-X01: frontend-compatible rollout and human wave acceptance are external; full release cannot pass from backend-only evidence.
