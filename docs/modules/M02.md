## Data safety, exit dan fallback

- Gate data: Patch live di repo tepat hanya dengan izin; no-delete termasuk session-store destroy, audit archive dan ORM cascade. Semua DB changes dibackup dahulu.
- Fallback: Disable risky feature/read-only; tidak membuka kembali known Critical route saat rollback.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: M02-X01: frontend legacy cookie/token handling, rich-text rendering/XSS dan real-browser compatibility harus punya bukti dari pekerjaan terpisah; tanpa itu full security release tetap BLOCKED.
