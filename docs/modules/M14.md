## Data safety, exit dan fallback

- Gate data: Use only synthetic/rehearsal load; SQL EXPLAIN of mutations not executed on live; backup before new indexes/schema.
- Fallback: Disable unsupported/slow report explicitly, no silent unscoped fallback.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: M14-X01: frontend integration/usability/accessibility tests dikerjakan kemudian; backend contract readiness tidak sama dengan frontend acceptance.
