## Tujuan dan scope

Logbook mendukung periode Class yang fleksibel dan review mentoring dengan histori.

- Prioritas/kompleksitas: **P1 / Medium**; owner/reviewer belum ditetapkan.
- Dependency: M05/M06, policy M04, audit M03.
- Coverage pekerjaan: Periods/deadlines, entries/revisions, submit/review/revise, personal mentor assignment history.
- Di luar scope: Tidak logbook UI, fixed four-month rule, specialization auth atau destructive reassignment.
- Area file: `internal/logbook/`, enrollment mentor assignment; legacy batch schedule mapping. Path Go/QA adalah usulan, belum file implementasi.
- Referensi: [ImplementationPlan §8/M12](../../../../ImplementationPlan.MD), serta §3–7 untuk domain/security dan §9–16 untuk data/test/cutover.

## Data safety, exit dan fallback

- Gate data: Backup/additive schema; no duplicate-row deletion; existing schedule raw preserved.
- Fallback: Archive unallocated history; pending review/mapping blocker diselesaikan sebelum Class cutover.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: approval operasional tetap terpisah bila menyentuh environment nyata; backend QA tidak memberikan izin deployment.
