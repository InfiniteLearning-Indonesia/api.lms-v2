## Rencana QA otomatis

Kode lapisan: API = Playwright Python request tests; GO = Go unit/integration (legacy memakai native tooling); DB = real PostgreSQL assertions; OP = operator/preflight/artifact check dengan human evidence bila diperlukan. Semua test di bawah baru spesifikasi.

| Test ID | Lapisan | Skenario dan expected evidence | Hasil |
|---|---|---|---|
| M16-T01 | OP+DB | Wrong target/backup/permission or real recipient configuration stops run; existing staging public unchanged. | NOT_RUN |
| M16-T02 | GO+DB+OP | No lost learner work; raw duplicate/orphan records retained; target totals checked per learner. | NOT_RUN |
| M16-T03 | GO+DB | Hash comparisons catch changes without updatedAt; absence observations not delete; rerun no duplicate. | NOT_RUN |
| M16-T04 | API+DB+OP | Cross-Class leak, invented grades/approval or missing critical file blocks unit; reviewers approve differences. | NOT_RUN |
| M16-T05 | OP | Mock-only/local-fixture pass cannot label production rehearsal done; latest real evidence required. | NOT_RUN |

Regression: M15 replay + API journeys for all selected domain features. Synthetic test writes only in separate rehearsal clone/schema.

Trigger yang akan dibangun: paket `IMPLEMENTED_PENDING_QA` → preflight → suite M16 → regression terdampak → shared gates → report → keputusan lanjut. Runner/tests belum ada; Markdown ini tidak men-trigger proses sendiri. Child case IDs `M16-T01-<case>` ditetapkan di manifest sebelum coding test; seluruh cases wajib harus lulus.

## Data safety, exit dan fallback

- Gate data: Explicit read/export/import authorization; backup every run; never execute module on credentials inferred from .env names.
- Fallback: Live remains owner; failed rehearsal retained restricted, next approved run uses clean new build.
- Exit backend: seluruh D dan shared gates applicable terverifikasi pada source/test/contract hash dan environment yang tepat. Critical failure/skip/blocker menghalangi kelulusan.
- External gate: M16-X01: data-owner/security/ops approvals and actual scoped production snapshot evidence cannot be replaced by automated test success.
