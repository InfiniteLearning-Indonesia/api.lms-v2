## Automation dan batas lanjut

M11 dan M12 bisa dikerjakan sebagai independent tasks bila dependency siap dalam scope batch. Jika salah satunya gagal, jangan mark B05 verified atau publish dependent report seolah lengkap.

Authority gate: Provider enablement/secret rotation hanya secara explicit. Performance tests pada approved synthetic workload, bukan live traffic. Frontend handoff berupa kontrak, bukan UI.

STOP jika: Attendance/grade global leakage, failed provider menjadi success palsu, uncontrolled fan-out/PII export atau data rule belum approved.

QA yang gagal memicu perbaikan+rerun dalam scope, bukan skip test atau otomatis lanjut dependency. Sesi/limit terputus → simpan checkpoint → verifikasi evidence/worktree saat resume. Tidak perlu memberi instruksi terpisah per M yang sudah masuk scope gelombang, tetapi izin operasi baru tetap diminta ketika diperlukan.
